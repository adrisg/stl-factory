# STL Factory

A web-based tool for generating STL files from SVG paths using an extrusion engine.

## Features

- SVG path parsing and processing
- 3D extrusion engine to convert 2D shapes into 3D geometry
- STL file export for 3D printing
- Interactive web interface

## Project Structure

- `index.html` — Main application interface
- `app.js` — Core application logic
- `extrusion-engine.js` — 3D extrusion engine
- `svg-parser.js` — SVG path parser
- `stl-exporter.js` — STL file generator
- `styles.css` — Application styles

## Usage

Open `index.html` in a browser to launch the application.
